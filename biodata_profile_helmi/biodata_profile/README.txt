BIODATA PROFILE - HELMI NASER

Struktur:
- index.html
- style.css
- asset/profile-placeholder.svg
- asset/family-placeholder.svg

Cara menjalankan:
1. Ekstrak folder biodata_profile.
2. Buka index.html menggunakan browser.
3. Edit data diri, data keluarga, jadwal kuliah, dan tautan Google Drive pada index.html.
4. Ganti gambar placeholder di folder asset dengan foto milikmu. Jika nama file berubah, sesuaikan atribut src di index.html.

Catatan:
Jadwal, data keluarga, email, dan tautan arsip masih berupa contoh/placeholder.
